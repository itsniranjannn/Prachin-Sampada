# Nepali style guide (everyday spoken Nepali, proofread)
The current Nepali reads like a word-for-word translation from English. Rewrite so it sounds like how a friendly Nepali guide actually talks today:
- Address the reader as तपाईं (polite). Natural sentence order (verb last), short sentences, no stacked clauses.
- Prefer common everyday words over Sanskritised/bookish ones: हेर्नुहोस् not अवलोकन गर्नुहोस्; सुरु not प्रारम्भ; बनाइएको not निर्मित; पुग्नुहोस् not प्रस्थान गर्नुहोस्; मन्दिर/दरबार/गल्ली/चोक/बजार are fine.
- Keep everyday English loanwords people really use: टिकट, फोटो, नक्सा, लगइन, मोबाइल, पासवर्ड, इमेल, क्विज, स्कोर, पोइन्ट, लोकेसन.
- Proper names of places/gods/dynasties stay in Devanagari as already spelled in the data (e.g. भक्तपुर, मल्ल, पशुपतिनाथ). Do not invent new spellings; keep names consistent with the existing *_np fields.
- Numbers/years: keep the digits the English uses converted to Devanagari digits where the existing text does; keep units (मिटर, किमी) natural.
- Proofread: correct हस्व/दीर्घ (इ/ई, उ/ऊ), ब/व, श/ष/स, ङ/ञ/ं use, spacing before/after punctuation (use । for sentence end), no stray English, no duplicated words, no machine-translation oddities.
- Meaning must stay faithful to the English source; do not add or drop facts.
- Games/UI buttons: short and natural ("सुरु गरौं", "अर्को प्रश्न", "सुराग हेर्नुहोस्").
